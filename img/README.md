# img — 사이트에 쓰는 이미지

여기에 넣은 파일은 **https://dreamworker0.github.io/gws-ai-training/img/파일이름** 으로 바로 열립니다.
`main` 에 올리면 1~2분 뒤 반영됩니다.

## 넣는 법

1. 이 폴더에 파일을 넣습니다.
2. 커밋해서 올립니다. (호야에게 말씀하시면 대신 합니다)

## 이름 짓기

띄어쓰기와 한글은 주소에서 깨집니다. **영문 소문자 + 붙임표**로 지어 주세요.

```
○  drive-shared-folder.png
○  a05-admin-console.jpg
✕  구글 드라이브 설명.png
✕  스크린샷 2026-09-20 오후.png
```

항목에 딸린 그림이면 **항목 번호를 앞에 붙이시면** 나중에 찾기 쉽습니다 (`a05-`, `b03-`).

## 형식과 크기

| | |
|---|---|
| 사진·스크린샷 | `.jpg` 또는 `.png` |
| 도형·도해·로고 | `.svg` 가 가장 깨끗합니다 |
| 가로 폭 | **1600px 이하**로 줄여서 넣어 주세요 |
| 한 장 크기 | **500KB 이하** 권장 |

큰 파일을 그대로 올리면 휴대폰에서 페이지가 느려집니다.
줄이기 번거로우시면 그냥 넣으시고 말씀만 주세요 — 제가 줄이겠습니다.

## ⚠️ 넣으면 안 되는 것

이 폴더는 **공개 웹**입니다. 파일 이름만 알면 누구나 볼 수 있습니다.

- 기관 내부 화면 스크린샷 (직원 이름·이용자 정보가 찍힌 것)
- 진단 결과지, 보고서 캡처
- 참석자 사진

교육 내용을 설명하는 그림, 도구 화면 예시, 강사님이 만드신 자료만 두십시오.
**사람이 찍힌 사진은 당사자 동의 없이 올리지 않습니다.**

## 아직 화면에 붙는 자리는 없습니다

지금은 폴더만 있습니다. 항목 페이지에 그림을 띄우려면 `data.js` 와 `app.js` 에
자리를 만들어야 합니다 — 넣으실 그림이 정해지면 그때 맞춰 만들겠습니다.
(그림 성격에 따라 본문 삽화로 넣을지, 갤러리로 넣을지가 달라집니다.)

당장 쓰시려면 주소를 직접 쓰셔도 됩니다:

```
https://dreamworker0.github.io/gws-ai-training/img/파일이름.png
```
